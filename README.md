
# Dental Office Website
This repository contains the source code for a modern, responsive dental office website implemented based on a Figma design. The site provides information about dental services, team members, appointments, and contact details.
The original design is available at Figma.
Features

Responsive design for desktop and mobile devices
Sections including Home, Services, About Us, Team, Contact, and Appointment booking
Modern UI components with accessibility features
Integration of charts and forms for enhanced user interaction

#Technologies Used

Framework: React.js with TypeScript
Styling: Tailwind CSS
UI Components: shadcn/ui (based on Radix UI), Material-UI
Build Tool: Vite
Icons: Lucide React
Forms: React Hook Form
Charts: Recharts
Other: Date-fns, Embla Carousel, React Router, etc.

This is a code bundle for Dental office website. The original project is available at https://www.figma.com/design/X75320GIj5JtRz3BMW4YK8/Dental-office-website.

## Running the code

Run `npm i` to install the dependencies.

Run `npm run dev` to start the development server.

To start the development server:textnpm run devOpen http://localhost:5173 in your browser.
To build for production:textnpm run buildThe built files will be in the dist/ directory.
